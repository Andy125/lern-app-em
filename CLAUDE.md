# Lernnest

Lern-App fürs iPad für eine Schülerin (Klasse 5, Gymnasium Baden-Württemberg). Reines JavaScript ohne Build in `public/`, Tests in `tools/`, Veröffentlichung über GitHub Pages.

- Für jede Änderung den Skill `lernnest-release` befolgen, für neue Inhalte zuerst `lernnest-inhalte`.
- Vor jedem Merge den Vater fragen.
- Das Repository ist öffentlich: keine Namen, Noten oder Fotos. Privates Material nur in `privat/`.
- Texte in der App: deutsch mit ß, Du-Form, ermutigend, keine langen Gedankenstriche.
